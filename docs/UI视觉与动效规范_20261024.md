# 原项目UI视觉与动效规范

用户于2026年10月24日指定的五项规范，适用于原Render前台、正式后台和GitHub Pages静态演示。小桃满模型、账号、数据与业务接口保持现有实现。

## 色阶与焦点

共用入口为 ui-system.css、ui-system.js。浅色Surface 0—3的HSL明度分别为94%、96%、98%、100%；暗色分别为7%、9%、11%、13%。相邻层级差2个百分点，交互控件以柔和投影及内环呈现聚焦，区域不使用1px实线边框。品牌色用于按钮和强调，照片保持原片。

输入焦点叠加柔和外阴影与inset内环；普通主题不显示突兀outline。系统强制高对比模式保留系统焦点标识。

## 暗色字重

主题按钮可在前台、后台登录页、正式工作台和静态演练工作台切换；未选择时跟随系统，主动选择后保存到浏览器。原项目使用 peach-ui-theme:v1，不改动副本的存储命名空间。

变量字体Peach UI统一使用 --weight-*，暗色值较浅色逐档减少40，包括400→360、500→460、600→560。64处字体简写补齐字重变量，防止简写重置为浏览器默认400。后台SVG图表随主题重绘并读取同一字重变量。

## 文字呈现与排版

输出按可见字符（含完整emoji字素）分组，ink-token从blur(6px)过渡至blur(0)，每字120ms，cubic-bezier(0.16,1,0.3,1)，间隔30ms。全文先占据布局空间，避免逐字出现导致段落高度持续跳变；可选择立即显示。

SVG统一vertical-align:-0.125em；数字统一tabular-nums；正文p统一text-wrap:pretty。所有details（含依据和智能结果折叠区）通过0fr→1fr的CSS Grid过渡，不用JavaScript测量内容高度。

## 弹簧与复制

桌面客服面板拖动后贴靠边缘，采用单位质量解析弹簧，stiffness=1200、damping=80、释放速度归零，路径单调、无回弹，并限制在可见窗口内。方向键可微调，Home居中。

复制成功的对勾采用stiffness=420、damping=20的解析欠阻尼轨迹生成Web Animations关键帧，有轻微回弹；反应按钮可复用springClick。对勾通过setTimeout(hide,2500)在2.5秒后还原。重复复制会重置同一按钮的还原计时。

尊重系统“减少动态效果”：输出直接显示全文，拖动直接到达终点，复制保持清晰的成功状态而省略弹簧运动。

## 发布和核验

动态站仅发布原仓库deploy/render-neon；静态站通过scripts/build-static.cjs构建并发布原仓库main。静态公开内容从原站脱敏发布资料生成，演练表单仍保存在浏览器，真实AI入口仍指向原Render前后台。

tests/ui-system.cjs验证两套主题、实际渲染字重差、焦点、折叠、流式参数、复制还原、弹簧单调性、后台图表及移动布局；tests/static-compact.cjs验证静态站的原项目入口和业务演练。
