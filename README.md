# 数商桃乡 · 网站与本地运营后台

**数商桃乡，让好桃被看见**。前台保留彩色产地照片、小桃满IP、玻璃质感及二级界面；后台以中文表单维护资料和经营记录。

## 开始使用

双击“启动后台.cmd”。首次安装依赖需要网络，此后使用本地数据库，不需要Neon或Render账号。

- 网站：http://localhost:8787/
- 后台：http://localhost:8787/admin/
- 首次登录信息：启动后生成在 .data/first-login.txt，首次登录必须改密码。
- 第一次进入后台先打开“项目与流程”，然后阅读“后台使用说明.md”。

关闭服务窗口会停止运行，数据保留在 .data/postgres。转移实际数据时，在“备份与运行”下载完整业务备份，不要删除数据库文件夹。

## 项目流程

事实核验 → 小桃满与渠道表达 → 消费者咨询 → 客户卡 → 原渠道成交台账 → 发货签收 → 售后回访 → 经营复盘 → 更新内容和规则。

16类网站内容：页面、商品、消费场景、批次、事实链说明、IP角色、IP栏目、调查分组、问卷选项、访谈、路线、FAQ、社交入口、赛事讲解、渠道模板、设置。

6类经营记录：客户回访、订单履约、市场问题、建议执行、小范围验证、青年协作验收。访问分析和经营看板分开统计；写入有权限、字段校验、版本及历史。

初始资料565条，其中问卷选项510条，不预置假订单、客户、销量或访问。产业端206、消费者243、学生与OPC437分别引用。

## 运行与验证

Node.js 22.16以上（22或24）+ Express；本地PGlite持久化PostgreSQL，设置DATABASE_URL后使用远端PostgreSQL适配器。图片实际字节存数据库，售后附件分权。

安装：npm ci。运行：npm start。服务端检查：npm test。测试使用独立内存数据库，不改使用者本地数据。浏览器检查入口为tests/admin-browser.cjs，静态回归为tests/interaction.cjs，需要本机Playwright和浏览器。

直接打开index.html或使用静态服务器/GitHub Pages时，仍是原静态演示，业务演练保存在当前浏览器。GitHub Pages不能运行Node后台。后台发布后刷新前台，或点击“刷新最新资料”。

付款、退款、物流、社交发布和协作结算在原渠道执行，本系统登记真实凭据。在线模型、支付、平台同步、自动营销、区块链尚未接入；本地模板与可解释规则不冒充在线AI。IP营销、销量、复购与效率效果仍需真实试行。

用户明确先完成本地。Neon/Render配置保留在.env.example、render.yaml和部署到Neon与Render.md；没有创建云服务、连接Neon或推送这次后台改动。Render只配置网页服务，不使用其PostgreSQL。
